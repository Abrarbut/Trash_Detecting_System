WHAT IS TRASHWATCH?
═══════════════════════════════════════════════════════════════════════════

TrashWatch is a real-time trash detection web application that:
  ✓ Detects trash objects in live video (laptop or mobile camera)
  ✓ Uses YOLOv8 state-of-the-art object detection AI
  ✓ Displays results with green bounding boxes and confidence scores
  ✓ Plays alert sounds when trash is detected
  ✓ Captures and stores images to cloud (Supabase)
  ✓ Logs all detections to a database
  ✓ Shows web dashboard with detection history

SETUP STEPS TO COMPLETE (15 minutes)
═══════════════════════════════════════════════════════════════════════════

Step 1: CREATE SUPABASE ACCOUNT (5 minutes)
  1. Go to https://supabase.com
  2. Sign up for free
  3. Click "New Project"
  4. Name: "trashwatch"
  5. Set strong password
  6. Choose region closest to you
  7. Wait 2-3 minutes for initialization

Step 2: CONFIGURE DATABASE (3 minutes)
  1. In Supabase: SQL Editor → New query
  2. Copy contents of supabase_setup.sql
  3. Paste into SQL editor
  4. Click Run
  5. You should see: "Setup complete!"

Step 3: CREATE STORAGE BUCKET (2 minutes)
  1. Click Storage on left sidebar
  2. Click New bucket
  3. Name: "snapshots"
  4. Check "Public bucket"
  5. Click Create

Step 4: GET API CREDENTIALS (2 minutes)
  1. Go to Project Settings (gear) → API
  2. Copy Project URL (https://xxxx.supabase.co)
  3. Copy anon public key (starts with eyJ...)
  4. ⚠️ DO NOT use service_role key

Step 5: CONFIGURE APP (2 minutes)
  1. Open .streamlit/secrets.toml
  2. Fill in your credentials:
     SUPABASE_URL = "https://YOUR_PROJECT_ID.supabase.co"
     SUPABASE_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  3. Save file

Step 6: RUN APP (1 minute)
  1. Execute: streamlit run app.py
  2. Browser opens to localhost:8501
  3. Done!

TOTAL TIME: ~15 minutes

TROUBLESHOOTING QUICK REFERENCE
═════════════════════════════════════════════════════════════════════════════

"Cannot open webcam"
  → Close apps using camera (Teams, Zoom, browser)
  → Check Windows: Settings → Privacy → Camera
  → Restart the app

"Nothing detected"
  → Lower Confidence Threshold to 0.30
  → Ensure good lighting
  → Get closer to camera
  → Object must be clearly visible

"Supabase not connecting"
  → Verify credentials in .streamlit/secrets.toml
  → No extra spaces or quotes
  → Use anon key, not service_role key
  → Check internet connection

"YOLOv8 download fails"
  → Check internet connection
  → Model (6MB) downloads on first run
  → Wait 1-2 minutes

"Port already in use"
  → streamlit run app.py --server.port 8502
