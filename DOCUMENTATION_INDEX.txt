📂 FILE DESCRIPTIONS
═════════════════════════════════════════════════════════════════════════════

PROJECT CODE FILES
───────────────────

app.py (15 KB)
  What: Main Streamlit web application
  Contains: Live detection, history, about tabs, all UI and logic
  How to use: Run with "streamlit run app.py"

requirements.txt (174 B)
  What: Python package dependencies
  Contains: List of all packages needed
  How to use: Install with "pip install -r requirements.txt"

supabase_setup.sql (467 B)
  What: Database schema creation script
  Contains: SQL commands to set up database tables
  How to use: Copy and paste into Supabase SQL Editor

run_app.sh (967 B)
  What: Startup script
  Contains: Bash script to easily start the app
  How to use: Execute "./run_app.sh" in terminal

CONFIGURATION FILES
────────────────────

.streamlit/secrets.toml
  What: Supabase API credentials storage
  Contains: Template for user's API keys
  Note: User must fill in their credentials here
  Important: This file is in .gitignore (won't be committed)

.gitignore
  What: Git configuration to prevent sensitive files being committed
  Contains: List of files to ignore
  Includes: .venv/, secrets.toml, model files
