## 🎯 Features Included

### Live Detection Tab
- Real-time video capture from laptop or mobile camera
- YOLOv8 object detection
- Green bounding boxes with labels
- Confidence scores
- Adjustable threshold (0.1 - 1.0)
- Alert sounds on detection
- Frame counter and statistics
- Automatic snapshot capture

### History Tab
- View all past detections
- Timestamp and confidence data
- Download as CSV
- Database connected

### About Tab
- Project information
- Troubleshooting guide
- Feature overview
- Tech stack details

### Sidebar Settings
- Camera source selection
- Confidence threshold slider
- Enable/disable alerts
- Enable/disable snapshots
- Statistics display
